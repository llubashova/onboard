📣 Маршрут специалиста по маркетингу

90 дней · 3 уровня · Яндекс.Директ, контент-план, email, TG-канал

Уровень 1. «Новичок»
📅 Дни 1–7

🔨 Задачи (70% — практика)

  • Изучить Яндекс.Директ, Юнисендер, конструктор сайта MODX Revolution
  • Изучить контент-план компании, профильный TG-канал
  • Подготовить 2–3 тестовых поста под контролем наставника
  • Изучить кейсы прошлых кампаний, шаблоны баннеров и текстов

🤝 Работа с наставником (20%)

  • Ежедневный контроль наставника в первые 3 дня
  • Встреча на 7-й день: обратная связь по первым постам

📚 Материалы Strive (10%)

  • Контент-план компании
  • Шаблоны баннеров и рекламных текстов
  • Кейсы прошлых рекламных кампаний
  • Инструкции по работе с Яндекс.Директ, Юнисендер
✅ Контрольная точка Заполнить Google Forms: отчёт о первых постах (охват, реакции аудитории)
Уровень 2. «Продвинутый»
📅 Дни 8–30

🔨 Задачи (70% — практика)

  • Запустить 1 рекламную кампанию в Яндекс.Директ (малый бюджет)
  • Подготовить email-рассылку через Юнисендер
  • Вести TG-канал: 1–2 публикации в день (~30–40 постов за три недели)
  • Работа с инфопартнёрами: заключить 2–3 договорённости
  • Аналитика: Wordstat, отслеживание конверсий

🤝 Работа с наставником (20%)

  • Еженедельные встречи с наставником
  • Разбор аналитики рекламных кампаний
  • Обратная связь по контенту TG-канала

📚 Материалы Strive (10%)

  • Шаблоны email-рассылок
  • Инструкции по настройке Яндекс.Директ
  • Гайд по работе с инфопартнёрами
✅ Контрольная точка Отчёт по первой рекламной кампании (бюджет, охват, конверсии)
Уровень 3. «Профи»
📅 Дни 31–90

🔨 Задачи (80% — практика)

  • Запустить полноценную рекламную кампанию для реального форума (Яндекс.Директ + email)
  • SMM: стабильная публикация 1–2 поста в день (~120–180 постов за два месяца)
  • Аналитика: отчёт по эффективности кампаний, корректировка стратегии
  • Администрирование Strive: актуализация базы знаний

🤝 Работа с наставником (15%)

  • Встречи по запросу
  • Обратная связь после запуска кампании
  • Контроль качества контента

📚 Материалы Strive (5%)

  • База знаний по маркетингу
  • Шаблоны аналитических отчётов
  • Инструкции по администрированию Strive
✅ Контрольная точка Понимание через ~30 дней: сработаемся ли дальше. Критерий — успешный запуск кампании для форума
