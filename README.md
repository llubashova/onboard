# 🎓 Auditorium Onboard

> **Система геймифицированной адаптации персонала** для ООО «Аудиториум СиДжи»  
> Дипломный проект по направлению «Управление персоналом», 2026

🌐 **Живой сайт:** [llubashova.github.io/onboard](https://llubashova.github.io/onboard/login.html)

---

## 📌 О проекте

Onboard — это веб-портал адаптации новых сотрудников, построенный на принципах геймификации. Новичок проходит три уровня адаптации (7 / 30 / 90 дней), выполняя задачи, набирая XP и получая бейджи достижений. HR-менеджер видит прогресс всей команды в реальном времени.

**Реализует концепцию ВКР:** _«Внедрение и разработка геймификации в адаптации персонала»_

---

## ✨ Ключевые возможности

| Функция | Описание |
|---|---|
| 🎮 Геймификация | XP, уровни (Новичок → Продвинутый → Профи), бейджи, прогресс-бар |
| 🗺️ 3 маршрута | Продюсер, Менеджер по продажам, Специалист по маркетингу |
| 📊 HR-дашборд | Прогресс всех сотрудников, фильтрация по роли и уровню, экспорт CSV |
| 👥 Многопользовательский | Приглашения по коду, роли сотрудник/администратор |
| 🔐 Авторизация | Регистрация по инвайт-коду, защита маршрутов по роли |
| 📱 Адаптивный | Работает на мобильных устройствах |
| 🌐 Без сервера | Хранение данных через JSONBin API |

## 🏗️ Структура проекта

```
onboard/
├── login.html          — Страница входа и регистрации
├── index.html          — Главная: маршруты + HR-дашборд
├── producer.html       — Маршрут: Продюсер (3 уровня)
├── sales.html          — Маршрут: Менеджер по продажам (3 уровня)
├── marketing.html      — Маршрут: Специалист по маркетингу (3 уровня)
├── admin.html          — Панель администратора
├── knowledge.html      — База знаний
├── feedback.html       — Обратная связь
├── auth.js             — Авторизация, роли, инвайты
├── db.js               — Слой работы с JSONBin API
├── game.js             — Геймификация: бейджи, счётчик дней
├── game.css            — Стили геймификации
├── header.js           — Хедер с кнопкой выхода
└── style.css           — Основные стили
```

## 🔑 Роли пользователей

| Роль | Доступ |
|---|---|
| **Продюсер / Sales / Marketing** | Свой маршрут, прогресс, бейджи |
| **HR-менеджер** | Все маршруты + дашборд прогресса сотрудников |
| **CEO / Директора** | Все маршруты + дашборд + панель администратора |

## 🛠️ Технологии

- **Frontend:** Vanilla HTML5 / CSS3 / JavaScript (ES6+)
- **Хранилище:** [JSONBin.io](https://jsonbin.io) — облачное JSON-хранилище
- **Деплой:** GitHub Pages
- **Шрифты:** Google Fonts (Inter)

## 🚀 Как запустить

1. Откройте [llubashova.github.io/onboard/login.html](https://llubashova.github.io/onboard/login.html)
2. Введите инвайт-код (получите у HR-менеджера) или войдите в существующий аккаунт
3. Выполняйте задачи, набирайте XP, прокачивайтесь!
