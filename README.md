# 🎓 Auditorium Onboard

> Интерактивная платформа адаптации персонала для Auditorium CG

[![GitHub Pages](https://img.shields.io/badge/demo-live-brightgreen)](https://llubashova.github.io/onboard/)

---

## 📋 О проекте

**Auditorium Onboard** — веб-платформа для онбординга новых сотрудников компании. Платформа геймифицирует процесс адаптации: сотрудник проходит структурированный маршрут из трёх уровней, выполняет задания и получает XP-очки, отслеживая свой прогресс в реальном времени.

Проект разработан в рамках выпускной квалификационной работы по теме **«Внедрение и разработка геймификации в адаптации персонала»**.

---

## 🚀 Функциональность

### Для сотрудников
- 📍 Персональный маршрут адаптации по роли (Продюсер / Менеджер по продажам / Специалист по маркетингу)
- ✅ Чек-листы задач с сохранением прогресса (JSONBin)
- 🏆 XP-система и три уровня: Новичок → Продвинутый → Профи
- 📚 База знаний по процессам компании
- 💬 Форма обратной связи

### Для HR и администраторов
- 👥 Таблица прогресса всех сотрудников в реальном времени
- 🔍 Фильтрация по роли и уровню
- 📊 Экспорт отчёта в Excel и PDF
- 🔑 Генерация инвайт-кодов для регистрации
- ⚙️ Управление пользователями: изменение ролей, блокировка, удаление
- ⭐ Повышение сотрудника до администратора

## 🛠️ Технологии

| Технология | Назначение |
|---|---|
| HTML / CSS / JavaScript | Фронтенд (без фреймворков) |
| [JSONBin.io](https://jsonbin.io) | Облачное хранилище данных (база пользователей и прогресса) |
| [SheetJS (xlsx)](https://sheetjs.com) | Экспорт в Excel |
| [jsPDF](https://github.com/parallax/jsPDF) | Экспорт в PDF |
| GitHub Pages | Хостинг |

## 📁 Структура проекта

```
onboard/
├── index.html        # Главная страница (дашборд сотрудника/HR)
├── login.html        # Страница входа и регистрации
├── admin.html        # Панель администратора
├── producer.html     # Маршрут адаптации: Продюсер
├── sales.html        # Маршрут адаптации: Менеджер по продажам
├── marketing.html    # Маршрут адаптации: Специалист по маркетингу
├── knowledge.html    # База знаний
├── feedback.html     # Обратная связь
├── style.css         # Глобальные стили
├── db.js             # Работа с JSONBin API
└── auth.js           # Авторизация и управление пользователями
```

## ⚙️ Запуск

Проект полностью статический — никаких зависимостей и сборщиков не требуется.

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/llubashova/onboard.git
   ```
2. Открыть `login.html` в браузере — или воспользоваться [live-демо](https://llubashova.github.io/onboard/).
